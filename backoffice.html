Como o dinheiro entra

Sua chave Pix e a conta do Mercado Pago. É o que o site usa para gerar a cobrança de cada consulta e de cada trabalho.

Pix Chave para receber
É para essa chave que o dinheiro das consultas vai cair.
Confira com calma. Uma chave digitada errado manda o dinheiro para a conta de outra pessoa, e esse dinheiro não volta sozinho.
Mercado Pago Conta para cartão
Você pega esse código dentro do Mercado Pago, em "Suas integrações". Ele é como uma senha: não mostre para ninguém.
